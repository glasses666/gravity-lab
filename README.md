# GravityLab 🌌

**GravityLab** is a high-performance, interactive N-Body gravity simulation engine designed for the web. It combines professional astrophysical algorithms (Barnes-Hut) with generative audio and artistic visuals.

![Banner](https://via.placeholder.com/1200x400.png?text=GravityLab+Preview)

## ✨ Features

- **🚀 High Performance**: Simulates hundreds of bodies using the **Barnes-Hut Octree** algorithm.
- **🖱️ Interactive Sandbox**: Click to track stars, inject new bodies, and control time/gravity.
- **🎵 Generative Audio**: Real-time **SpaceSynth** engine creates eternal ambient music.
- **🌍 Multi-language**: Supports 18 languages (English, Chinese, Japanese, Spanish, etc.).
- **🖥️ Cross-Platform**: Runs in any modern web browser.

## 🚀 Quick Start (One-Click Run)

### Linux & macOS
Open a terminal in this folder and run:
```bash
./setup_and_run.sh
```

### Windows
Double-click the script file:
```
setup_and_run.bat
```

*(Note: You must have [Node.js](https://nodejs.org/) installed on your system)*

## 🛠️ Manual Installation

If you prefer the command line:

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
```
