## 仿真模型

35 个节点、111 条有向边、三条跨河通道、一条单行路段；中心、北桥、南桥限高分别为 2.5、3.0、3.8 米。信号灯具有固定周期、方向放行区间及相位偏移。支持事故、施工、排队、学校过街、人工指挥、积水待核实、倒树、通行权限、临时封闭、已清理事件、矛盾通报和预设湿滑减速。

Jev 把事件转成 block / delay / ignore / review。代码负责几何、时间、方向、合法边、车辆限高、已知排队秒数和事件有效区间。明确硬封闭和独立的未核实隔离不能被模型解除。

搜索状态为 (路口, 绝对整数秒)，包含合法原地等待边。启发式为欧氏距离 / 最大自由流速度。最早到达相同时优先较短距离，避免无意义绕圈。默认 1 秒离散、900 秒时域；最优性仅针对这套有限模型。路径带 world version 和快照 hash，世界变化后拒绝使用旧路径。

## 验证

17 个单元测试通过。其中包含 30 组固定随机种子的 A* 与时间扩展 Dijkstra 对照，并覆盖：红灯等待、非 FIFO 延误下主动等待、封闭区间与穿越时段重叠、单行道、限高、错误模型结果不能解锁硬封闭、低置信度转待核实、非法响应、过期路径、出发点等于终点、有限时域无路、等待优于绕圈。

HTML 报告通过 Chromium/Playwright 的 DOM 注入渲染验证：1380×1000 与 390×844；检查了场景切换、三种路线视图、播放/暂停、无路可达和移动端横向溢出。报告是实际 API 结果的离线回放，交互不发起模型请求，也没有凭证。
